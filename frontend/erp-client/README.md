# کلاینت فرانت‌اند سامانه سازمانی ERP (React + Vite + TypeScript)

کلاینت تحت وب سامانه جامع سازمانی ERP مبتنی بر React 19، Vite، TypeScript و Tailwind CSS 4 با رویکرد معماری ویژگی‌محور (Feature-Based Architecture).

---

## ۱. مشخصات و تصمیمات فنی

- **فریم‌ورک:** React 19
- **ابزار ساخت:** Vite 6
- **سیستم استایل:** Tailwind CSS 4 + متغیرهای رنگی اختصاصی (Design Tokens)
- **مسیریابی:** React Router v7
- **مدیریت وضعیت سرور:** TanStack Query v5 (کشینگ، تلاش مجدد هوشمند و همگام‌سازی)
- **مدیریت وضعیت کلاینت:** Zustand v5 (کاربر فعال، شرکت جاری، تم و سایدبار)
- **مدیریت فرم‌ها و اعتبارسنجی:** React Hook Form + Zod
- **سیستم اعلان‌ها:** Sonner (راست‌به‌چپ با زبان فارسی)
- **تقویم و تاریخ:** پشتیبانی از تقویم هجری شمسی و فرمت استاندارد UTC
- **جهت صفحه:** ۱۰۰٪ راست‌به‌چپ (RTL) با فونت استاندارد Vazirmatn Variable

---

## ۲. ساختار پوشه‌ها (Feature-Based Architecture)

```text
src/
├── app/             # پیکربندی کلی، ارائه‌دهنده‌ها (Providers)، مسیرها و Layoutها
├── core/            # کلاینت مرکزی Axios، کانتکست چندمستأجری و احراز هویت
├── shared/          # کامپوننت‌های عمومی UI، فرم‌ها، جدول‌های مالی و ابزارها
├── features/        # ماژول‌های مستقل تجاری (Dashboard, Accounting, Sales, ...)
├── styles/          # استایل‌های سراسری، توکن‌های تم و تایپوگرافی
└── main.tsx         # نقطه ورود برنامه
```

---

## ۳. دستورات اجرا و توسعه

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه (پورت ۳۰۰۰)
npm run dev

# بررسی خطاهای تایپ‌اسکریپت و بیلد پروداکشن
npm run build

# اجرای لینتر کدها
npm run lint
```
