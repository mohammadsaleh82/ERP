# ERP.Modules.Sales

This module contains the domain, application, infrastructure, and contracts for Sales.

## Internal Structure
- **Domain/**: Entities, ValueObjects, Enums, Domain Events, Exceptions
- **Application/**: Features, DTOs, Validators, Mappings, Services
- **Infrastructure/**: DbContext, Configurations, Repositories, External Integrations
- **Contracts/**: Public API, DTOs, and Integration Events accessible by other modules
