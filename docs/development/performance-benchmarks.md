- همه گزارش‌های تک‌درخواستی روی یک میلیون ردیف **زیر ۳ ثانیه** — تجمیع تک‌GROUP BY با Projection سبک؛ بدون N+1.
- صفحه‌بندی روزنامه مستقل از حجم دفتر (۱۴۰ms).
- ۲۰ درخواست موازی روی SQLite فایل‌محور به‌دلیل قفل فایل کند است؛ سناریوی هم‌زمانی عملیاتی روی PostgreSQL سنجیده شود (Npgsql Pool). آستانه تست برای SQLite ۹۰s است.
- حافظه پایدار (~۴۴۰MB) — هیچ مادی‌سازی کامل دفتر در حافظه انجام نمی‌شود.
