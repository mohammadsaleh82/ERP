# استانداردهای کدنویسی و کنوانسیون‌های توسعه (Coding Conventions)

این سند استانداردهای الزامی کدنویسی در لایه‌های Backend و Frontend سیستم ERP را تبیین می‌کند.

---

## ۱. استانداردهای بک‌اند (.NET 10 / C# 14)

### الف) سبک نام‌گذاری و تعریف انواع
- کلاس‌ها، رکوردها، متدها و پراپرتی‌ها: `PascalCase`.
- پارامترها و متغیرهای محلی: `camelCase`.
- اینترفیس‌ها: با حرف `I` بزرگ شروع می‌شوند (`ITenantContext`).
- نام‌گذاری جداول و ستون‌های دیتابیس: `snake_case`.

### ب) قوانین لایه‌بندی ماژول
1. **Domain:**
   - موجودیت‌ها از `Entity<TId>` یا `Entity` و `AggregateRoot<TId>` ارث‌بری می‌کنند.
   - لایه Domain به هیچ وجه نباید به لایه Infrastructure، پکیج‌های EF Core یا کنترلرهای API وابسته باشد.
   - منطق‌های تجاری و اعتبارسنجی‌های ذاتی باید در دامین محصور باشند.
2. **Application:**
   - خدمات Application از طریق Mediator یا Service کلاس‌ها هماهنگ می‌شوند.
   - ورودی‌ها با FluentValidation اعتبارسنجی می‌شوند.
   - خروجی‌ها با مدل `Result<T>` بازگردانده می‌شوند.
3. **Infrastructure:**
   - پیاده‌سازی DbContext، نگاشت Fluent API و دسترسی به سرویس‌های خارجی.
   - کلیه DbContextها باید از `BaseDbContext` ارث‌بری کنند.
4. **Contracts:**
   - فقط DTOها، رویدادها (`IntegrationEvent`) و اینترفیس‌های عمومی ماژول جهت فراخوانی توسط Composition Root در این پوشه قرار می‌گیرند.

### ج) مدیریت استثناها
- از `try-catch`های توخالی به شدت پرهیز شود.
- استثناهای منطقی تجاری از `AppException`, `NotFoundException`, `ValidationException` ارث‌بری می‌کنند.
- خطاهای پیش‌بینی‌نشده توسط `GlobalExceptionHandlerMiddleware` به فرمت RFC 7807 تبدیل می‌شوند.

---

## ۲. استانداردهای فرانت‌اند (React 19 / TypeScript / Tailwind)

### الف) ساختار کامپوننت‌ها
- کامپوننت‌ها به صورت Function Component با نام `PascalCase` تعریف می‌شوند.
- نام فایل کامپوننت‌ها: `kebab-case.tsx` (مانند `button.tsx`, `tenant-switcher.tsx`).
- کلیه کامپوننت‌ها باید به صورت صریح Typings داشته باشند؛ استفاده از `any` اکیداً ممنوع است.

### ب) دسترسی‌پذیری و راست‌به‌چپ (RTL)
- در طراحی از کلاس‌های استاندارد Tailwind با پشتیبانی از منطق منطقی استفاده شود (مانند `ms-2` به جای `ml-2`، `start-0` به جای `left-0`).
- کلیه فونت‌ها و اعداد با فونت استاندارد Vazirmatn نمایش داده می‌شوند.

### ج) استیت‌ها و دریافت داده
- داده‌های سرور باید منحصراً توسط TanStack Query مدیریت شوند.
- استیت‌های UI محلی با `useState` یا فرم‌های React Hook Form مدیریت شوند.
- استیت‌های سراسری فقط با Zustand پیاده‌سازی شوند.
